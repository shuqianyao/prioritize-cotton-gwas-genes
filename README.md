# 棉花 GWAS 候选基因优先级评估

这是一个用于棉花产量和纤维品质性状研究的 Codex Skill。它按性状和 GWAS 区间评估全部候选基因，整合功能缺失变异、错义变异、功能注释、表达、同源基因、文献、遗传定位和调控靶基因八类证据，输出优先级、评分依据和证据缺口。

## 功能注释与变异解读

| 适用情况 | 分析内容 |
|---|---|
| 每个候选基因 | 报告功能名称、相关转录本、蛋白结构域和注释来源，区分实验依据、同源推断和自动注释 |
| 基因编码酶 | 整理可核实的催化反应、底物和功能位点，评估变异可能怎样影响催化活性或蛋白丰度 |
| 变异位于启动子 | 比较等位基因是否改变潜在甲基化位点或 CG、CHG、CHH 序列背景，有匹配数据时再检查实际甲基化和表达差异 |
| 变异位于 CDS | 按转录本预测密码子和蛋白变化，检查错义变异的保守性、功能位点以及提前终止或移码造成的预测截短 |

同一基因可以同时适用多个分析分支。预测结果用于筛选值得进一步验证的候选，甲基化和酶活变化需要相应的观测或实验支持。

## 从 GWAS 信号到候选基因

先按区间报告位点可信度与跨环境或独立群体复现情况，再用局部 LD、条件关联和单倍型检查哪些候选可以区分。有匹配分子数据时，结合顺式 eQTL、等位基因特异表达或共定位评估调控变异的靶基因。八类评分用于初筛，综合优先组会记录调整理由和仍需并列的候选。[查看定位与调控证据规则](references/locus-evidence.md)

## 在 Codex 中使用

下载或克隆仓库，将含有 `SKILL.md` 的整个 `prioritize-cotton-gwas-genes` 目录放到个人 Skill 目录，或放到项目的 `.agents/skills/` 下。然后在 Codex 中输入：

> 使用 $prioritize-cotton-gwas-genes 评估我提供的棉花纤维长度 GWAS 区间。按区间输出候选基因排序、逐基因功能注释和评分来源，对酶编码基因、启动子变异和 CDS 变异分别给出适用的分析，并标出待补数据。

提供物种、性状、参考组装及注释版本、lead SNP、区间边界及定义，以及已有的候选基因、变异、表达、同源或文献资料。启动子和 CDS 解读需要与组装版本一致的坐标和等位基因，必要时提供参考序列与转录本注释。

## 运行样例

在包含 `SKILL.md` 的目录执行以下命令。排序脚本使用 Python 3 标准库，读取已整理的证据分数。

```bash
python3 scripts/rank_candidates.py assets/demo.csv --output ranked_demo.csv
```

合成样例的默认排名为 `DEMO_A`、`DEMO_B`、`DEMO_C`，总分依次为 **73.75、37.50、13.75**。

使用自己的 CSV 时，每个文件对应一个性状和区间，每行对应一个基因。各项分数取 0–1。空白表示未评估，`0` 表示评估后无支持。输出保留输入字段，并添加排名、总分、已评估得分、证据完整度和证据等级。可用 `--weights` 调整权重，比较首选基因是否稳定。
